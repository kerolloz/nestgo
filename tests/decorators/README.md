# decorators fixture

Guards the one compiler behaviour NestJS cannot tolerate drifting: the
`design:paramtypes` metadata that dependency injection reads to resolve
constructor arguments.

`expected-di-metadata.txt` was generated by real `tsc@5.9.3` — the TypeScript
version `@nestjs/cli` 11.x depends on. `scripts/verify-decorator-emit.sh`
compiles this fixture with `ttsgo` and asserts the emitted metadata still
matches, then runs the output. CI runs it on every push.

The fixture has no npm dependencies; `src/decorators.ts` contains local
stand-ins for the NestJS decorators so the check tests the compiler, not NestJS.

Regenerate the baseline (requires network, installs tsc temporarily):

    ./scripts/verify-decorator-emit.sh --regenerate
